# My Snake Again

This is a browser-based Snake game built with plain HTML,vanilla CSS, and JavaScript. You can play it in your web browser without any additional setup.You are tasked to control the snake and eat the fruit to grow longer while avoiding crashing !!

## What you can do

- Move the snake with the arrow keys or WASD
- Eat the fruit to grow and increase your score
- Avoid crashing into your own tail
- Restart the game quickly after a game over


## Technologies used

-HTML
-Vanila CSS
-JavaScript
